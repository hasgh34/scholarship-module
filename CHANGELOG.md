# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии: [SemVer](https://semver.org/lang/ru/).

## [0.1.0] - 2026-11-24

### Added
- Расчёт академической, повышенной (ПГАС) и социальной стипендий по правилам предметной области.
- Расчёт рейтинга студента: взвешенная сумма критериев (средний балл, НИР, общественная деятельность) по шкале 0-100 и уровень рейтинга.
- Прозрачная конфигурация правил в `config/rules.yaml` с проверкой (сумма весов равна 1, числовые значения, обязательные параметры).
- Аудит: расшифровка рейтинга по критериям с указанием, кто и сколько баллов начислил; объяснение каждого решения о назначении или отказе; журнал действий `audit.jsonl`.
- Экспорт результатов в PDF для приказа (таблица выплат, итог, версия правил, поля для подписей).
- Командная строка: `python -m scholarship.cli`.
- 41 unit-тест: нулевые баллы, максимум, границы порогов, льготы, задолженности, некорректные данные, конфигурация, журнал, PDF, CLI.

### Fixed
- Нет (первый релиз).

### Known issues / ограничения
- Данные хранятся в JSON-файлах, база данных не используется.
- Суммы стипендий и пороги в `rules.yaml` примерные, перед использованием их нужно сверить с положением о стипендиях.
- Нет графического интерфейса и разграничения прав пользователей.
- Журнал аудита - обычный файл: защиты от ручной правки нет (цепочка хэшей запланирована).
